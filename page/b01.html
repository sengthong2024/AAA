ສາຂາຕິດຕັ້ງ ແລະ ສ້ອມແປງ

ອຸປະກອນເຕັກໂນໂລຊີ

Technology Installation and Repair

1. ແນະນຳສາຂາຮຽນ

ສາຂາຕິດຕັ້ງ ແລະ ສ້ອມແປງ ເປັນສາຂາທີ່ສຶກສາກ່ຽວກັບ ການຕິດຕັ້ງ ການກວດສອບ ແລະ ການສ້ອມແປງອຸປະກອນ ເຕັກໂນໂລຊີ ເຊັ່ນ ຄອມພິວເຕີ, ໂນດບຸກ, ເຄື່ອງພິມ ແລະ ອຸປະກອນເຄືອຂ່າຍ.

ນັກຮຽນຈະໄດ້ຮຽນຮູ້ການຕິດຕັ້ງ ອຸປະກອນໃໝ່ ການກວດຫາສາເຫດ ຂອງອຸປະກອນເສຍ ແລະ ການສ້ອມແປງໃຫ້ກັບມາໃຊ້ງານໄດ້ປົກກະຕິ.

2. ສິ່ງທີ່ນັກຮຽນຈະໄດ້ຮຽນ

  • ຄວາມຮູ້ກ່ຽວກັບ Hardware ແລະ Software
  • ການຕິດຕັ້ງ ແລະ ປະກອບຄອມພິວເຕີ
  • ການຕິດຕັ້ງລະບົບ Windows
  • ການຕິດຕັ້ງໂປຣແກຣມ ແລະ Driver
  • ການຕິດຕັ້ງສາຍເຄືອຂ່າຍ LAN ແລະ Wi-Fi
  • ການກວດສອບ ແລະ ສ້ອມແປງອຸປະກອນ
  • ການບຳລຸງຮັກສາອຸປະກອນໃຫ້ໃຊ້ງານໄດ້ດົນ

3. ທັກສະດ້ານການຕິດຕັ້ງ ແລະ ສ້ອມແປງ

🔧 ການສ້ອມແປງຄອມພິວເຕີ

ຮຽນຮູ້ການກວດສອບ ແລະ ແກ້ໄຂບັນຫາ ຄອມພິວເຕີ.

💻 ການສ້ອມແປງໂນດບຸກ

ກວດສອບຈໍພາບ, ແປ້ນພິມ, ແບັດເຕີຣີ ແລະ ອຸປະກອນພາຍໃນ.

🖨️ ການສ້ອມແປງເຄື່ອງພິມ

ກວດສອບ ແລະ ແກ້ໄຂບັນຫາເຄື່ອງພິມ ທີ່ບໍ່ສາມາດໃຊ້ງານໄດ້.

🌐 ການຕິດຕັ້ງເຄືອຂ່າຍ

ຮຽນຮູ້ການຕິດຕັ້ງ ແລະ ແກ້ໄຂບັນຫາ ເຄືອຂ່າຍອິນເຕີເນັດ.

4. ຂັ້ນຕອນການຕິດຕັ້ງ

  • ສຶກສາຄວາມຕ້ອງການຂອງອຸປະກອນ.
  • ກະກຽມເຄື່ອງມື ແລະ ອຸປະກອນ.
  • ກວດສອບອຸປະກອນກ່ອນຕິດຕັ້ງ.
  • ດຳເນີນການຕິດຕັ້ງຕາມຂັ້ນຕອນ.
  • ຕິດຕັ້ງໂປຣແກຣມ ແລະ Driver.
  • ທົດສອບການເຮັດວຽກຫຼັງຕິດຕັ້ງ.

5. ຂັ້ນຕອນການສ້ອມແປງ

  • ຮັບຟັງອາການເສຍຂອງອຸປະກອນ.
  • ກວດສອບ ແລະ ວິເຄາະສາເຫດຂອງບັນຫາ.
  • ກຳນົດວິທີການສ້ອມແປງ.
  • ເລືອກໃຊ້ເຄື່ອງມືໃຫ້ເໝາະສົມ.
  • ດຳເນີນການສ້ອມແປງຢ່າງລະມັດລະວັງ.
  • ທົດສອບອຸປະກອນຫຼັງສ້ອມແປງ.

6. ອາຊີບທີ່ສາມາດເຮັດໄດ້

  • ຊ່າງຕິດຕັ້ງຄອມພິວເຕີ.
  • ຊ່າງສ້ອມແປງຄອມພິວເຕີ.
  • ຊ່າງສ້ອມແປງໂນດບຸກ.
  • ຊ່າງຕິດຕັ້ງເຄືອຂ່າຍ.
  • ພະນັກງານບຳລຸງຮັກສາອຸປະກອນ IT.
  • ເປີດຮ້ານຮັບຕິດຕັ້ງ ແລະ ສ້ອມແປງ.
